Oblique Uploader

A private publishing tool for the YouTube channel Oblique (@ObliqueStories).

Oblique Uploader is used only by the owner of the Oblique channel to upload the channel's own videos, thumbnails and captions through the YouTube Data API. It is not offered to the public and has no other users.

This application uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Privacy Policy

Last updated: November 9, 2026

What the app accesses. With the channel owner's permission, the app uses the YouTube scopes needed to upload videos, set thumbnails, add captions and read the status of videos it uploaded.

How the data is used. The access is used only to publish the owner's own content to the owner's own channel and to check whether uploaded videos are still awaiting review. No other personal data is collected.

Storage. The authorization token is stored only on the owner's private server, readable by the owner alone. Video files and metadata stay on that server.

Sharing. No data is sold, shared with third parties, used for advertising, or used to train AI models. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Access can be revoked at any time at myaccount.google.com/permissions.

Contact. Through the Oblique YouTube channel.
